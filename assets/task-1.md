# TODO App - Верстка

Необходимо реализовать `TODO` приложение на основе готовой верстки.

Задачи:

- Перенести верстку `TODO` из примера в `React` приложение.
- Разбить верстку на компоненты и отобразить на экране визуальную часть `TODO`. Вынести в отдельные компоненты:
  - `Task` - одна задача;
  - `TaskList` - список задач;
  - `NewTaskForm` - форма для добавления;
  - `Footer` - футер с информацией и кнопками;
  - `TasksFilter` - фильтры в футере.
- Сделать, чтобы все данные в `Task` передавались через `props` из верхнего компонента приложения.

Особенности:

- Пока не реализовывать отображение строки `"created 5 minutes ago"`.

Время создания задачи должно быть классом `Date`.
Для отображения в качестве строки использовать функцию библиотеки `date-fns`.
